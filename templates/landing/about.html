About AI Smart Attendance System

Modern Attendance Management Using Face Recognition & QR Code

Project Overview

AI Smart Attendance System is a web-based attendance management application developed using Python, Flask, MySQL and OpenCV.

The system provides secure attendance through Face Recognition and QR Code scanning while generating smart reports and analytics.
